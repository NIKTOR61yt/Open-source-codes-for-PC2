# Open-source-codes-for-PC2
Открытые коды для Pixel Combats 2 с моих режимов. Используются для решения проблем.
---
# Не забывайте, что используются ещё стандартные методы и справочник нужен в первую очередь создателю и критика принимается.
Обычные методы не подаются через призму новизны и универсального подхода. Иногда они нужны здесь, чтобы показать откуда идут корни.
---
При использовании используются импорты, если вы плохо знакомы с импортом рекомендую ознакомиться в справочниках.
